# DRUG FLY — $DRUGFLY

Одностраничный лендинг мемкоина. Чистый статический HTML/CSS/JS, без сборки.

**Идея:** муха из гроу-тента №4 считает себя пчелой. Она облетает и опыляет каждый куст
лично, поэтому весь урожай объявляет своим и продаёт как продукт собственного опыления.

## Что внутри

- Фоновый canvas «гроу-тент»: кусты, которые качаются, лампа-пульсация, 15 мух летают
  между кустами, зависают над ними и сыплют пыльцу.
- Гейт CLICK TO ENTER (авто-открытие через 25 с), запускает музыку.
- Мини-игра **THE POLLINATION**: муха следует за курсором, куст опыляется, если
  крутить вокруг него по стрелке (2–3 оборота), против стрелки — пыльца слетает.
  8 кустов, манифест и лог справа, победа = дождь монет и бутонов.
- 8 карточек лора, которые открываются по одной за куст.
- Клик по персонажу — дождь монет + звук.
- Музыка и звуки на Web Audio, без аудиофайлов. Кнопки SOUND / MUSIC.

## Настройка перед листингом

В начале `index.html` блок SETTINGS:

```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку — пока пусто, кнопка неактивна
```
